# 素材盘点与源时间证据

## 不同来源分别准备

| 来源 | 初始化需要核实 | 深入审阅的方法 | 保留的制作依据 |
| --- | --- | --- | --- |
| 带口播的视频 | 实际时长、尺寸、方向、是否有音轨；已有代理、缩略图、转写 | 开头、中段、结尾等少量实际帧了解画面；按转写候选句查看相邻帧；必要时查真实静音区间 | 主讲句的源时间、上下文、可删候选及其证据；现场声需要保留的范围 |
| 旅拍、活动、补充画面 | 时长、尺寸、方向、是否可解码；必要代理与缩略图 | 从代表性帧开始，用镜头边界定位变化，再对候选动作前后取帧 | 能被观察到的画面、动作范围是否已确认、适合放在哪个叙事位置 |
| 独立录音、采访、旁白 | 实际时长、音轨信息、波形；需要内容剪辑时转写 | 读带源时间的文稿和静音候选；需要判断噪声或表演效果时保留人工试听待办 | 保留句与上下文；与视频的同步关系是否已确定；缺乏同步依据时不编造对齐点 |
| 音乐、环境声、音效 | 实际时长、音轨信息、波形；用户用途 | 按用户明确用途安排候选；无法实际试听时不描述节奏、情绪或声学质量 | 来源、拟用范围、入场位置与音量计划；不默认转写或降噪 |
| 图片、截图 | 尺寸、方向、文字可读性、实际画面 | `inspect_video_frame` 使用 0 秒查看；检查画幅适配和显示文字所需时间 | 可观察内容、适合的章节、预期停留时长；需要运动效果但工具未支持时保持静态 |
| 已生成场景或 TTS | 真实成功产物、`scene` 或 `speech` 来源元数据、实际时长 | 复用已有成品并核对文案与当前目标；TTS 文本不当作精确转写 | 成功任务/真实素材 ID、生成参数、可复用的用途；不重复生成等待中的产物 |

所有媒体只能使用当前 Panel 实际提供的准备与分析。代理和缩略图用于可靠读取，不是将原片永久转成低画质。Agent 不接受任意路径、下载地址或 shell 命令作为替代方案。

## 多素材的两层审阅

第一层做可追踪的筛选。先盘点全部已导入素材，按已有元数据、用户明确标记和少量实际观察安排审阅顺序；优先目标相关、覆盖关键叙事和用户指定的来源。可从每条候选视频约 2–3 个源时刻开始，短片或静态画面可更少，长片按镜头变化选点。这是初筛策略，不是“检查三个点就懂了整段”的判据。

第二层围绕要入片的范围深入。读候选句前后文，查看动作起止或转场前后的实际帧，保留完整语义和动作余量。采访先挑完整回答再压缩停顿；教程先确认操作与结果对应，再删等待过程；旅拍不能因为转写为空就淘汰画面。

一批结束即保存当前审阅范围和下一批来源。工具轮次受限时优先保存已确认候选与未完成事项，不重复初筛全部素材。没有看过的素材应标为待审阅，不能擅自写“已淘汰”。已经排在用户时间线上的片段不是天然废片；理解现有顺序的用途后才在全流程中改动。

## 记录可复查的源时间

时间证据必须来自工具返回值：视频帧观察记录实际 `seconds`，转写记录实际起止秒，静音和镜头分析记录真实区间/切点。转写时间属于源文件；编辑操作和制作单片段时间使用 30 fps 的整数帧。用 `round(seconds * 30)` 转换并限制在素材合法长度内，采用 `[inFrame,outFrame)` 半开范围。

制作单文字中写清证据强度，例如“源 12.4 秒帧可见入口；源 13.1–16.8 秒转写介绍地点；动作结束尚未检查”。根据一个截图不能声称整个源范围都稳定清晰。源时间及 ID 用于复查，剪辑后序列时间在粗剪顺序确定后另算。

`preparation` 可能按 Host 持久素材 ID 返回；工程素材 `id` 与 `mediaId` 可能不同。准备/取帧/剪辑参数使用各工具要求的工程 ID，关联准备结果时利用实际映射，不能靠相近文件名猜。

## 能力不足时的可执行结果

- 没有 ASR：仍可按实际帧整理画面及用户已给文稿；记录需要转写的来源，不能把估算时间写成真实字幕。
- 只有浏览器试听：可以整理配音文案和声音偏好，不能声称已有可导出语音。
- 原声增强不可用：保留原声与处理需求，不能把降低音量说成降噪。
- 缺少素材或关键镜头：用现有证据调整叙事，必要时列出具体补拍/补录项；不拿示例或虚构画面冒充用户素材。
