# Video Studio · 视频工作台 0.7.1

## 0.7.1：播放不再每次重复复制原片，轨道可删除

- **播放**：此前每次编辑后点播放，都会让 CodeShell 重新复制全部原片（实测约 10 MB/s，近 1 GB 素材每次等 1–2 分钟），界面却一直显示“正在生成快速预览画面”。现在已校验的原片按工程保存一份（硬链接，不额外占用磁盘），编辑后再次播放直接复用；外部引用的素材复用前会先向主程序确认仍然可用。复制与转码期间显示实际进度和已等待时间，可随时取消。工程首次播放时每个新素材仍需复制一次原片。
- **轨道**：时间线轨道头新增删除按钮。空轨道一键删除；有片段的轨道先确认“删除轨道和 N 个片段？”，均可一步撤销。锁定轨道和磁吸主轨不可删除，并说明原因。

## 待发布：暂停视频与离屏渲染的寻帧修复

预览与导出在寻帧完成后冻结实际解码的视频帧，并核对帧自身的时间范围；旧画面尚未更新时继续等待，不把视频时钟变化当作画面就绪。帧时间戳恰好等于目标时可直接确认画面，包括录制素材时长为零且没有新呈现通知的首帧。每次重新加载解码器时先确认并记录首帧时间，再进行时长探测或寻址；首帧对象随即释放。音轨早于视频首帧的 WebM，即使没有呈现回调且帧时长为零，也只接受与该资源已确认首帧相同的画面，不因视频帧时间晚于播放时钟而卡住。其他帧时长缺失或容器取整时，可用对应画面的呈现回执确认；回执先于寻址完成到达时保留到就绪再核对，旧寻址的延迟回执不能确认新目标。连续时间落在同一源帧时，不强制等待新的呈现回调。小数微秒的帧边界取不早于目标的微秒位置，避免被浏览器截断到前一帧；帧对象暂未可读时在原截止时间内重试。替换、取消和关闭时释放冻结帧，原有截止时间与错误提示保留。Agent 的独立画面采样也核对并冻结实际帧后再编码 JPEG，完成或失败后释放，不改变正在预览的素材位置。原片预览也复用这一寻帧流程，重新打开工程后绘制已核对的冻结帧；开始播放后跟随实时画面，替换素材或隐藏面板时释放缓存。真实 Linux 导出及完整界面仍须通过验收，未发布新的 Panel 版本。

## 0.7.0：各功能直接编辑多轨工程

字幕、口播、粗剪加入成片、配音替换、AI 规则草案与导入方案、自动制作以及本人口播流程，现在都直接读写多轨工程。真实拍摄的素材（时长不是整帧）、附加画面轨、文字、变速和转场不再让这些功能显示“没有素材”、按钮变灰或点击报错。

- **字幕**：字幕页与“更多工具 → 语音字幕”共用同一个面板，可在播放头添加、修改时间、删除、套用样式，导入/导出 SRT。调整时间不会拉长成片，打字机和淡入淡出动画随长度缩放。
- **口播**：删减在任意时间线模式下都可用，链接的增强音频、B-roll、背景音乐、字幕和标记同步平移；可选“仅口播及关联轨”。
- **粗剪**：“加入位置”可选成片末尾（默认，记住上次选择）或播放头；连续加入按顺序排列，保留素材真实尾部。
- **配音**：在属性面板对任意音轨上的生成配音“修改文案 / 重新配音”，原位替换。
- **AI 制作**：15 秒规则草案真正输出 15 秒成片；方案审阅显示前后时长和各轨变化，工程变化后方案标为过期，不会静默套用。自动制作可在本次请求授权内使用多轨编辑工具。
- **本人口播**：文稿草稿、确认、录音绑定与对齐基于多轨工程计算，确认结果不受系统语言影响；已确认的旧工程在无法校验时提示“回到审阅”。
- **语音转写**：未就绪时说明缺少 whisper 命令还是 base 模型，并提供“重新检测”；在 Homebrew 等常见目录中查找工具。

易用性：素材卡“＋”默认接在主画面轨末尾；新增“添加文字”，标题放在所有画面轨之上，时间线显示文字内容；时间线工具栏提供“磁吸 / 自由”切换；不可用的按钮说明原因（键盘与读屏可读）；颜色字段提供取色器；新建工程有文字标签并在有风险时确认；轨道更紧凑，1280×900 可见 5 条轨；宽度 900px 以下使用“画面 / 素材 / 属性”切换布局。修复点击时间线右侧片段后时间线持续重绘的问题。

## 0.6.6：缩短 4K 视频首次预览等待

播放预览现在生成最高 1080p 的快速兼容画面；正式导出仍使用全尺寸、无损的高精度素材准备。对同一段 4K 原片，本机实测首次画面准备约 13 秒、预览文件约 10 MB；此前高精度路径需数分钟并生成约 1 GB。预览仍保留原始帧时间，素材和工程格式不变。

## 0.6.5：播放准备状态与更新恢复

## 0.6.0：完整多轨编辑与开放工程交付

编辑工作台使用统一工程：多层画面、音频、字幕和复合序列均保留精确时间。支持多选/框选、原位复制、分组、磁吸排列、逐帧裁剪、关键帧与贝塞尔曲线、曲线变速/倒放/定格、手动蒙版、调色和基础转场。轨道可独立调音量与声像，点和范围备注可编辑并定位。

字幕可从真实音源识别，按剪辑的源时间映射；支持逐条样式、关键词强调、逐词高亮、SRT、翻译候选和双语。声音工具提供降噪、响度均衡、人声/伴奏分离、音高、自动压低配乐和长音频流式预览。分离引擎需要明确安装固定模型；原片始终保留。

同一工程可以管理多条独立序列、复合片段和多机位。机位支持真实声音对齐、手动校正、同时监看和切换录制；切画面保持连续主声音。预览与后台导出共用画面合成与声音规划。

**打包工程**生成开放 `.mimiproject`，包含完整工程和媒体；**工程同步**在选择的外部同步目录保存不可变版本，有冲突时审核并合并。存储服务可替换，实际跨设备文件传输由对应客户端完成。采用其他版本前保存历史，通过版本快照恢复；普通编辑支持撤销。此格式不兼容剪映私有草稿，也不携带系统字体；换设备需要相同字体，界面会提示可能缺失的字体。

支持 H.264、HEVC、VP9、ProRes、多规格批量后台导出、取消和恢复，是否可用以本机处理器检查为准。当前输出为 SDR Rec.709、8 位；不声称 HDR、广色域或透明视频交付。AI 画面处理与在线素材/模板库按计划延后。

兼容 0.5.15 与 0.5.16 草稿，升级前保存原始工程备份；0.5.16 的轨道顺序、隐藏/静音/锁定、位置缩放、音频长尾和仅主轨磁吸语义保留。

AI 导出先返回准备回执，重复请求复用同一次操作；准备期间保持面板打开。收到实际后台任务后可继续编辑并查询结果，成片经过验证后才显示完成。

## 0.5.15：我的声音库与按需视频预览

声音准备会明确指出下一步：选择或录制本人参考录音、填写实际逐字稿、准备模型、生成并确认真实试听。已提取录音但未填写逐字稿时，可直接定位到需要填写的位置；安装引擎不等于已经生成了自己的声音。

浏览器直接录制的 WebM 音频即使没有保存时长字段，Audio8 和 Qwen 也会读取实际音频包的时长，避免将有效录音误报为“无法读取录音时长”；仍要求参考录音为 3 至 30 秒。

确认试听后，**保存到我的声音库**会把录音、试听和配方保存在本机 Video Studio 专属数据目录。其他工程和工作区可选择同一声音；使用时自动将参考音频登记到当前工作区，保留当前剪辑和音轨。已打开的其他面板可通过**刷新状态**更新声音库。没有本地进程接口的环境保留同工作区工程复用。跨工作区复制显示实际进度，未完整保存的声音不会显示为成功。

视频工程恢复只登记素材和已有封面，按需加载当前预览；可见卡片的封面通过串行临时解码生成，完成即释放。封面与预览一样核对并冻结实际首帧，不依赖新的呈现回调，也不直接绘制会变化的视频表面。没有回调但已成功解码的暂停素材仍可生成封面；真正的解码错误、取消或原有一秒截止时间到达时，封面仍是可选结果，不阻止其他可用素材导入。完成或失败都释放冻结帧。隐藏面板会释放视频缓冲，重新显示后可继续预览。素材数量不会增加常驻视频播放器的数量，原文件、剪辑和素材元数据保留。

0.5.14 新增 **自由时间轴**：点击主序列的“磁吸排列”或按 **M** 关闭磁吸后，画面可拖到指定时间、保留空隙，也可在右侧输入精确位置。**边缘吸附**独立由 **N** 开关，拖动时 **Alt** 暂停吸附，**Esc** 取消。单画面轨不允许重叠，空隙在预览和导出中保留为黑场，独立音乐/配音继续按时间轴播放。重新开启磁吸会收拢空隙，整次切换可撤销。

## 先给长素材做粗剪

1. 点素材卡上的 **粗剪**，或从左侧 **粗剪** 进入，先处理当前素材。上方选择素材、播放和定位，下方依次标记 I/O、管理保留段、加入成片；底部的 **批量工具** 默认收起。中间预览显示原片，时间位置与成片分开。
2. 播放原片，按 **I** 记开始，按 **O** 记结束，再按 **＋** 或点 **保存保留段**。继续看、继续标，留下多段。O 会包含当前帧；也可直接输入秒数或 `时:分:秒:帧`。
3. 在保留段列表中逐段预览、命名、勾选和上下调整顺序。点击已有段可修改范围；**B** 在当前源位置切开所选段，**反选保留**改为保留所有勾选范围以外的部分。撤销使用 **⌘/Ctrl Z**。
4. 点 **加入 N 段到成片**，将当前素材已勾选的保留段按列表顺序入轨。旁边的 **加入位置** 默认为 **成片末尾**：画面接在整条成片的最后（磁性时间线接在主画面轨末尾），声音接在所有声音轨中最后一段声音之后。改选 **播放头** 时，画面与声音各自从成片播放头起连续排列；磁性时间线在最近的片段交界处插入（不会拆开转场或编组），后面的片段连同关联声音和字幕整体后移；自由时间线只放在空闲位置，播放头处已有片段时自动换到空闲轨道或新建轨道，不会覆盖已有内容。加入后播放头停在新片段之后，连续多次加入会按先后顺序排列。上次选择的加入位置会被记住。实拍素材的最后一段保留原片完整结尾；声音可以比画面长。一次撤销可撤回本次入轨，保留粗剪标记。加入后自动返回成片并预览第一个新片段，可继续配音、字幕与精剪；再次进入粗剪可继续已有标记。
5. 需要交给 LosslessCut 时，点 **下载 LosslessCut CSV**；在 LosslessCut 打开同一原文件，再导入此清单。CSV 只包含当前素材已勾选段的秒数与名称，不包含媒体文件。

需要多素材处理时，展开底部 **批量工具**，或先在素材页勾选多份，再点 **批量粗剪**。这个入口只展开批量工具，**AI 辅助粗剪**仍保持收起。展开 **选择/调整 N 份素材** 确认队列，用 **上一素材 / 下一素材** 逐条预览、标记；各自尚未保存的范围在本次会话切换素材时保留，已保存的段随工程持久保存。点 **统一加入 N 段到成片**，按队列素材顺序、各素材保留段顺序一次入轨，位置同样按 **加入位置** 选择；未标记的素材会跳过。一次撤销可撤回本次整批入轨，保留粗剪标记。

在 **批量工具** 内展开 **统一去片头片尾 / 保留指定时长**，设置两端去除的时长，或选择保留开头、中间、结尾的指定时长，再生成候选。去头尾后没有剩余的素材会明确列出并跳过；短于指定保留时长的素材保留整段。逐段预览、取消勾选不需要的候选，点击 **保存勾选的 N 段**。生成和丢弃候选不会修改已有标记或时间轴。

需要 AI 初筛时，直接展开独立的 **AI 辅助粗剪**。分析一份时选 **当前素材**，核对素材名称、填写要求，点 **AI 粗剪当前素材**；分析多份时选 **所选 N 份素材**，可用 **选择 / 调整素材** 核对队列，再点 **AI 粗剪所选 N 份素材**。也可从批量工具的 AI 入口打开多素材配置。展开和切换范围本身不会启动分析，单素材分析不会重设多选队列。

AI 每批处理最多 **3 份**，并连续处理整个所选队列，例如 4 份按 3 + 1 两批处理；每批在主程序支持的最多 20 轮内，为真实取帧、补充观察和提交候选留出空间。视频至少查看开头、中间、结尾附近以及候选范围内的真实画面，音频使用真实转写。没有转写时会显示具体缺项：本机需要安装 openai-whisper（`whisper` 命令）并准备 base 模型 `~/.cache/whisper/base.pt`，装好后在“任务”页点 **重新检测** 再重试。关键帧初筛不等于逐帧理解连续动作或检测抖动，候选的精确边界需要预览确认。AI 分析会将采样画面、选用的转写和任务要求交给当前模型连接处理。

AI 候选、已完成批次和任务进度按工程持久保存。收起工具后，AI 摘要仍显示已有分析状态或待审阅候选数量，展开可继续查看；收起不会取消已启动的分析。已有任务会单独显示原来的分析对象，切换新分析范围不会替换它。取消保留已完成结果，**继续未完成的素材**从未完成批次重新观察；启动与停止确认期间不能重开或丢弃，重启恢复也先确认旧任务已停止。明确 **丢弃本次分析** 后才可放弃尚未完成的队列重新开始，已保存标记仍保留。审阅并保存候选后，单素材用 **加入 N 段到成片**，多素材可用批量工具中的 **统一加入**。不要把暂存的 AI 候选或仅生成的统一裁剪候选当作已经保存的粗剪标记。

若旧版任务因参数错误停在 0/N，更新到 0.5.9 后打开原工程，在 **AI 辅助粗剪** 点击 **继续未完成的素材**。原队列、素材和已完成候选可继续使用，不需要重新导入素材或重新建立队列。

已保存的粗剪标记随工程自动保存并进入撤销历史。桌面引用在原文件仍可访问时重启恢复预览；移动原片后用 **重新连接原文件** 接回。普通浏览器导入的副本保存在网站数据中，清除网站数据或只移植工程 JSON 时需要重连。面板时间以固定 30 fps 换算，原文件不被修改。最终 MP4 / WebM 继续使用现有成片渲染流程；本功能不提供编码流复制式无损视频导出。设计与官方资料见 [粗剪说明](../../docs/video-studio-rough-cut-design.md)。

## 换更好的声音，或使用本人声音

在“配音”页先选模型，点击 **试听所选声音 · 前 120 字**，到“制作任务”听真实生成结果。满意后再生成全文并加入音轨。**浏览器读稿 · 非模型效果**只让浏览器读文字，不代表所选模型的声音。

- **Edge TTS**：选择微软在线声音，点击安装并验证引擎；生成时会把文案发送给在线服务。
- **Kokoro**：安装固定本地模型后离线生成，实际语言和音色以模型目录为准。
- **在线中文配音**：在 CodeShell 设置 → 模型连接 → 文字配音添加“硅基流动中文配音 · CosyVoice”，填写服务商 API Key，然后回到面板刷新。也可使用已配置的 OpenAI 兼容语音合成连接。费用与音色可用性由服务商决定。
- **Audio8 本人声音**：本次优先接入 0.6B ONNX INT4 版，当前提供 Apple Silicon Mac 初始化，至少 4 GB 内存与 4 GB 可用空间。需要本机已有 uv、FFmpeg/ffprobe，Python 3.12 与固定模型可在初始化时准备。
- **Qwen 本人声音**：选择 **Qwen3-TTS · 本人声音克隆**，点击安装并验证引擎。当前本地实现限 Apple Silicon Mac，至少 8 GB 内存与准备时 6 GB 可用磁盘；固定模型和依赖预计下载约 2.4 GB。需要 uv、FFmpeg/ffprobe；Python 3.12 会在私有运行目录按需准备。安装进度和失败原因显示在制作任务中。

本人声音的操作顺序：

1. 在“自己录”录制 **3–30 秒**本人声音并保存，或导入已有音频。建议 10–20 秒、无背景音乐、正常语速；参考使用这条音频的完整源文件，时间轴裁剪不会改变参考长度。
2. 在配音页选择该参考录音，并在 **参考录音逐字稿**原样填写录音里说的话，最多 1000 字。另一个 **配音文案**框填写要新读的内容，每次最多 2000 字。
3. 先生成短试听检查发音和相似度，再生成全文。本地声音合成不向语音服务上传参考录音或文稿；使用 AI 初始化或制作时，所选逐字稿与文案会交给当前 AI 连接处理。
4. 生成结果保留所用参考素材编号与逐字稿；再次点击音轨中的“修改文案 / 重新配音”可恢复这份配方。声音准备卡的选择与已命名声音按工程保存，切换工程不会把上一工程的参考录音带入新工程。模型不会承诺声音完全一致，背景噪声和参考录音质量会影响结果。

0.4.3 修复裁剪或重排素材后，媒体定位误差导致播放头越过片段起点并报“时间码”的问题，同时限制时间轴片段选择的位置范围。原工程可直接继续使用。

## 先看草稿，再录自己的声音

0.4.2 新增随包 [`video-studio:narration-workflow`](agent/skills/narration-workflow/SKILL.md)，支持“我拍了一堆素材，输入一些想法，先帮我写稿、剪视频和配字幕；我觉得 OK 后再自己口播”的流程：

1. **素材与想法**：导入视频、图片或已有录音，在 AI 制作页说明主题、重点和目标时长，启动草稿制作。
2. **文案与视频草稿**：工作台按真实素材写入可编辑文稿，安排画面和临时字幕。此时字幕是按待录文稿估时的草稿，不是真实转写或精确对齐；草稿完成后停止等待审阅，不自动生成 TTS 或导出。
3. **确认后本人录音**：预览并调整文案、画面和字幕，点击确认后把当前文稿带入提词器。用户自行选择设备并开始录制；保存后将这条具体录音用于当前制作，也可以选择已导入的本人录音。确认文案不会自动开启麦克风。
4. **按真实声音完成**：继续口播对齐时，读取选定录音的真实转写和时长，安排整段人声与画面，替换本流程的临时字幕，保留其他标题。声音比草稿长时调整画面，不靠截掉句尾适配草稿；未有真实转写时保留工程和录音并显示缺项。
5. **检查并导出**：语义变化需回到审阅；对齐成功后再生成有声 MP4。后台任务成功才是实际成片，仍可试听并返工。

确认状态、文稿、临时字幕归属和选定录音随工程保存。用户手动修改已批准的文案、剪辑、音轨或字幕，会回到审阅，旧批准不能继续用于新内容；单纯素材预处理不会误当成改稿。保存改好的文案会同步更新本流程的临时字幕；换用第二份口播时移除上一份本人口播音轨，避免两段人声叠播。真实录音仍保留在素材库，不因返工被覆盖。普通“自动做一版”和使用 TTS 的全流程入口保持原有用途。

这条完整流程需要面板的本地媒体工具与语音转写实际可用；本机 Whisper/模型未就绪时不能完成真实口播字幕对齐。独立浏览器可录制和手动编辑，不能用浏览器文案试听或估计字幕代替桌面 ASR。

## 初始化与全流程 Skill

在 **AI 制作** 页，可以点击 **初始化制作单**，或直接点击 **开始全流程制作**。两个入口会在真实 Agent 任务中加载对应的随包 Skill，无需另行安装个人 Skill。

- [`video-studio:video-init`](agent/skills/video-init/SKILL.md)：检查实际环境与能力，按视频、音频、图片分类准备，审阅必要文稿与关键帧，保存目标、叙事、素材用途及源范围、下一步和待补内容。初始化保存制作单，并可按用户选定的声音执行引擎准备、参考片段提取和短句试听；试听只存入素材库，不改剪辑、不生成整篇旁白或导出；已排队的素材任务结束后才保存完成。环境缺项会如实保留。
- [`video-studio:video-workflow`](agent/skills/video-workflow/SKILL.md)：从制作单继续选片、粗剪、原声或配音、字幕包装、精修和真实导出。也可在无制作单时先做初始化步骤，然后继续成片。它按目标调用已有 `video-production` 执行规则，需要安装指定配音引擎时调用 `tts-setup`。

制作单保存在工程的 `workflow` 中，AI 页可展开查看，JSON 备份、历史版本和重开恢复均保留。阶段记录用于继续工作，不等于该阶段已实际完成；只有导出任务成功才显示 MP4 完成。增加素材或手动修改后，继续制作会重新核对工程、已准备结果和待审内容，不盲目重做已有语音或覆盖新剪辑。

**拍了一批视频时的推荐顺序：**

1. 先确定用途、受众、主线、目标时长和横竖屏；没有强偏好时给出一个可修改默认。
2. 导入原素材，保留原声与原片；分别准备视频预览、录音转写、图片画面，不对所有素材一律转写。
3. 根据文稿与关键帧建立主线、补充画面、旁白、音乐和待审素材的选择，记录真实源时间与取舍原因。大量素材先粗看再深入重点，未看的不冒充已分析。
4. 先剪出叙事完整的粗版，再去有证据的重复、停顿和无关部分。已有剪辑是起点，补拍只补必要片段。
5. 处理本人原声，必要时生成配音并按真实音频长度安排画面；再做字幕、章节与画面节奏。
6. 核对完整句尾、音量、源范围、字幕时间和缺失媒体，导出后检查实际结果。当前模型使用单路磁吸画面序列，补充画面是顺序镜头，不代表多视频叠加。

示例：**“这批是我的探店素材，做一条 60 秒竖屏短片。保留我自己的口播，用店面和食物镜头补充，加字幕后导出。”** 如果只想先规划，选择初始化入口；做过初始化后，点击“按制作单继续制作”。

## 0.4 已接通的工作流

- **自己录**：麦克风、摄像头、屏幕加麦克风，设备选择、音量指示、3 秒倒数、暂停继续、结束试听和重录。提词器可编辑稿件并调整滚动速度。只在点击准备时请求系统权限；离开预览释放设备，未保存的录制不会静默丢弃。录屏是否有系统声音取决于实际音轨与平台。
- **保存原片**：桌面通过带序号/偏移的 32 KiB 分块写入 Host，原片进入素材库后由面板工具检查实际媒体信息；浏览器将本人录制存为 IndexedDB Blob，重开同一浏览器可恢复。浏览器存储可能被清理，保留“下载原始录制”入口，工程 JSON 不包含原片。
- **口播整理**：将原片或独立录音加入时间轴任意轨道，在“口播”页准备并分析。使用真实词时间戳、静音检测和重复段落生成候选；逐项试听、勾选、跳过、批量删减与撤销。默认整条时间线同步删去所选时刻（画面、关联声音、空镜、音乐、字幕和标记一起前移，其他空隙保持不变）；勾选“仅口播及关联轨”时只剪口播和与它关联的声音。变速、倒放片段按实际播放位置删减；保留呼吸余量；无词级时间戳时不伪造精确口头词剪切。
- **原声优化**：轻度/均衡两档，降噪和响度均衡独立开关；低频清理、确定性降噪、两遍响度测量与限幅生成完整 WAV。应用到未变化的工程时保留片段位置、源范围和音量并静音旧声；处理期间工程变更则只保存新音频，不覆盖当前剪辑。
- **模型与声音**：系统 TTS、微软 Edge 在线语音、本地 Kokoro、Audio8 / Qwen3-TTS 本人声音克隆，以及配置的 OpenAI 兼容语音合成连接。Edge/Kokoro/Audio8/Qwen3-TTS 可从配音页安装并实际验证，也可让 LLM 使用随包 `tts-setup` Skill。安装、失败、取消与就绪状态可查看；支持用所选模型生成前 120 字真实试听，不把浏览器试听当成模型结果。
- **文稿与包装**：AI 润色存为可编辑的工程文稿并填入配音编辑区，保留原录音；只改文稿时不自动导出。字幕提供经典底框、醒目描边和简洁白字三个模板，预览、WebM 与本地 MP4 使用一致样式。

竞品对标参考 Descript、CapCut、VEED、Premiere 和 Riverside，详细证据与差距见[能力矩阵](../../docs/video-studio-product-research.md)。这一版补的是录制到成片的本地工作流；眼神修正、数字人、生成式镜头、多人云录制、自动主体跟随和云端协作仍未接入，不显示为已具备能力。

## 安装与开发

源码位于 `apps/video-studio/`，以 TypeScript 维护；`panel.build.json` 声明浏览器与本地工具入口。运行仓库构建后，将 **`panels/video-studio/`** 作为安装目录。安装包包含浏览器 `.mjs` 产物、只读制作 Skill 和独立 Node.js 媒体工具 `app/tools/media-runtime.mjs`；固定模型版本配置随工具发布，模型权重及独立运行环境在初始化时下载到面板数据目录。旧 `voice-runtime.mjs` 入口仅保留兼容，当前全部媒体制作走统一入口。

推荐使用 **CodeShell 0.9.14**。0.5.6 的原文件引用需要该版本提供的通用持久文件授权、引用校验与只读 Range 访问接口；旧 Host 仍可使用复制保存路线。既有持久制作基础需要 **CodeShell 0.9.11+ / Panel API 14**，以及实际开放的 `tasks.start/get/list/cancel/retry`、`resources.get/read/list`、本地运行权限、同源 Range 媒体访问和持久文档接口。面板通过 `getContext().availableMethods` 与 `capabilities` 检查实际可用能力，不按版本号假定接口存在。剪辑、AI 编排、媒体处理和模型安装仍由面板负责。独立浏览器仍可打开带真实旁白的演示、手动剪辑、导入 SRT 和实时导出 WebM，界面明确显示能力差异。

## 制作流程

1. **导入素材**：在支持引用的桌面上，默认由系统文件窗口授权原视频、音频或图片，保存只读引用，导入不复制整片；也可选择复制保存。文件夹可一次导入或在面板打开时自动检查新增素材，重启后继续自动检查需要重新连接文件夹。导入先读取预览所需信息，后续制作按需准备代理、波形、静音区间、镜头边界或转写；处理任务可使用必要的临时输入。任务页显示进度、失败原因和可用的重试入口。
2. **自动制作**：在 AI 制作页描述目标、时长与比例。初始化入口加载 `video-studio:video-init`；全流程入口加载 `video-studio:video-workflow`，按素材类型决定预处理和转写，并使用 `video-production` 的执行规则。Agent 使用实际关键帧、源秒时间戳文稿与检测结果规划，不用文件名冒充画面理解。
3. **可编辑结果**：固定 30 fps 磁吸画面序列，支持切分、裁剪、排序、删除、音量与字幕；独立音乐/配音轨有源范围、时间轴位置与 0–200% 增益。音轨和字幕随被编辑的画面时间区间移动。
4. **文字配音**：在“配音”页选择实际可用的模型、声音与语速，编辑文案或从当前字幕填入，支持字数统计、估时与浏览器文案试听。完成后以原始音量加入播放头所在的独立音轨。完整音频、文案、模型、声音、风格说明和语速随工程保留。在片段属性中修改配音，重新生成会保留原位置和音量替换该音轨；若原音轨已被进一步编辑，则只保存新素材。也可明确选择作为新配音加入。画面太短会明确提示，并保留完整源音频供延长后使用。自动制作先读取真实语音时长，再编排画面与完整配音。
5. **生成场景**：自动制作或“生成章节 / 解释场景”创建参数化 HyperFrames 源码，并真实渲染成可复用 MP4 素材。面板工具保存源码与参数产物，按内容哈希及渲染版本复用已验证缓存，Host 只负责通用资源入库。
6. **后台交付**：导出 MP4 使用持久原素材、独立混音和烧录字幕。任务成功后可在任务页播放和保存。只读工程 JSON、SRT 或排队成功不代表视频已经完成。

## 恢复与版本

Host 工程文档上限 2 MiB，保留最近 20 次持久保存。自动剪辑先保存恢复版本，再以工程 ID、请求 token 和 `baseRevision` 校验整批修改；过期请求不能覆盖新的手动编辑。撤销/重做在当前工作台内即时可用，跨重启可通过历史版本恢复。

切换工程前归档，最近工程最多 10 份；容量不足时移除较早快照。JSON 备份只包含编辑信息与持久素材 ID，不包含媒体本体。转移机器时仍需一起保存原素材。

预处理、安装、配音与 MP4 导出均提交为通用持久任务，关闭面板后继续运行。主程序重启后保留实际中断状态与已完成产物；面板为本地任务声明可重试，为可能产生远端费用的在线配音声明人工恢复，需先检查已有结果再重新创建，避免重复收费。取消确认表示任务已经停止，停止过程会单独显示。自动制作的目标与阶段也会保存，重开面板后根据任务结果继续；每轮最多 20 次模型交互，自动续作最多三轮，不无限重复提交失败工作。

## 环境与实际边界

- **FFmpeg / FFprobe**：真实预处理与 H.264 MP4 输出所需。任务页显示是否就绪。
- **播放准备与原始素材**：第一次使用的原始素材需由主程序完整复制一次到本地任务目录（大文件可能需要几分钟，状态栏显示“正在把原始素材交给本地任务”和已等待时间）。校验过的原始素材按项目以硬链接保留一份，修改工程后再次播放不再重新复制；外部链接素材每次先向主程序确认仍可用且大小一致，文件丢失或变化时回到主程序复制并如实报错。保留的原始素材在 14 天未使用且不属于刚提交的工程时于下次提交快照时清理；旧快照目录目前不会自动清理。
- **文字配音**：使用本机已有 macOS 系统音色与 FFmpeg；Edge TTS 为第三方在线客户端，Kokoro 使用独立本地运行环境与已验证模型。Edge/Kokoro 引擎安装目前需要已有 uv、Python 3.12、FFmpeg/ffprobe，Edge/Kokoro 支持 macOS/Linux ARM64/x64。所有配音适配、固定依赖与模型由视频面板管理，通过通用任务接口启动随包 Node.js 工具；Audio8 / Qwen 当前初始化限 macOS ARM64，实际依赖、安装状态和失败原因以本地检查为准。在线 TTS 使用 CodeShell 设置 → 模型连接中配置的“语音合成”连接，支持 OpenAI 兼容 speech 接口；只有真实可用配置会进入模型列表，密钥不会传入浏览器页面，仅通过授权的私有配置交给本次独立工具使用。普通浏览器的语音仅用于试听文案，不会冒充可导出的音轨，也不会冒充在线模型的实际声音。配音生成不依赖 Whisper 或 HyperFrames。
- **语音转写**：使用本机 openai-whisper（`whisper` 命令）与 base 模型 `~/.cache/whisper/base.pt`，未就绪时说明缺少哪一项；装好后在“任务”页或字幕面板点 **重新检测**，也可继续使用 SRT/手工字幕。只在有真实转写结果时支持基于口播的判断；不伪造词级对齐。
- **字幕渲染**：MP4 烧录字幕由随包工具启动独立 Chrome/Chromium 绘制，不依赖主程序的页面渲染器。缺少可用浏览器时显示实际失败。
- **HyperFrames**：检测已有 CLI、Node 22+、Chrome 与编码工具；不静默安装或升级。适配层支持快照导入已有自包含工程，当前面板工具开放参数化章节与解释场景。没有接入镜头重绘或任意生成式视频服务。
- **演示 / 浏览器素材**：内置 24 秒示例自带实际中文旁白，浏览器可直接播放并导出有声 WebM；未修改过的旧默认示例会安全接入旁白，用户编辑过的工程保持原样。示例画面是浏览器绘制，不是持久视频源，不能送入本地 MP4 渲染。浏览器 WebM 仍可导出示例与临时文件；实时录制最长 10 分钟，必须保持面板打开且可见，进入后台会取消。
- **视觉证据**：Agent 可请求源视频代表性帧或图片，得到最长边 640 像素 JPEG；单帧不等于理解完整动作。静音能量和镜头边界仅是检测结果，不证明内容价值。
- **媒体与任务边界**：工程使用素材 ID，通过同源 `/media/{id}` 播放和取帧；设备录制仍通过限额、顺序校验的 32 KiB 分块上传。已入库素材由通用资源接口直接准备到任务目录，工具产物按内容哈希入库，不再逐块搬运模型输入输出。随包入口及哈希经过主程序核验；通用任务接口管理进程、进度、取消与记录，面板维护模型、算法、预处理阶段和恢复策略。工具不接受自定义模型下载地址，不把视频或密钥塞进业务 JSON。

### LAN browser identifiers (development build)

Project, asset, caption, editor transfer, synchronization, voice and render operation
IDs use the same Panel-owned UUID helper. When a LAN HTTP browser lacks
`crypto.randomUUID`, the helper generates UUID v4 values from
`crypto.getRandomValues`; it never falls back to time or `Math.random`. Existing
saved IDs are preserved. This fixes identifier creation, not the remaining Host,
recording, preview, background-task or mobile workflow adaptation requirements.
