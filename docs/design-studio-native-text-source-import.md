# Bounded native Text source export and import

The isolated candidate adds read-only native observation capture to the existing
JSON_REST_V1 export and admits a bounded uniform metric subset as editable
canonical Text. It does not authorize updates, clearing or deletion of original
native range Text. Those source patch guards remain closed.

All new execution evidence is CPU, VM or replay of retained observations.
**Actual production native execution: NOT_RUN.** No glyph or native pixel parity
has been established. The older prepared production probe embeds the earlier
runtime and cannot validate this candidate without a separately pinned rebuild.

## Source and ownership

Official REST nodes remain intact. A supplemental outer `nativeTextRanges` table
holds version1, the actual optional pluginId, and exact native Text IDs mapped to
`{source, hint?}`. No pluginId is invented when the SDK does not expose one.
[Figma's pluginId API](https://developers.figma.com/docs/plugins/api/figma/)
explicitly permits an absent ID. A missing ID skips optional author hint reads;
independent current source admission remains available.

A complete capture has the exact scalar catalog, every styled segment field,
and exactly seven getter observations for each identical segment boundary.
Explicit missing, mixed, error, the observed getter value1, every raw numeric
value and authored UTF16/LF boundaries remain raw. A codec source labelled
`bound` or `uniform` without the full capture catalog cannot activate admission.

Every REST node must match its native object, type, full child order and exported
root ancestry. Repeated overlapping sources must agree on complete raw bytes and
ownership. Reserved raw lookalike carriers explicitly refuse export rather than
overwrite unknown official data. Existing stale carriers cannot substitute for
a failed fresh capture. A failed optional hint read leaves fresh native evidence
and a warning; malformed or stale saved hints remain available as raw fallback.

Capture is staged against the first official REST export. After every awaited
REST/image/PNG/SVG export, one final synchronous pass rechecks native object
identity, parent/child order, ancestry, all observed Text fields and the relevant
preview/mask/paint context. Changes refuse the whole export. This proves freshness
of the complete **observed SDK fields against that REST basis**. It does not
claim atomic freshness of arbitrary REST-only unknown fields or the whole file.
Export calls no native setters, plugin-data writes, selection or page mutations.

## Independent canonical projection

The canonical metric patch comes from complete uniform SDK values. SDK PERCENT
line height is divided by100 exactly; converting the candidate back must equal
the original observed SDK value. SDK PIXELS stays an exact explicit pixel value.
There is no rounding, fitting, epsilon or authored metric restoration. REST
lineHeightPx and REST percentage representation remain unchanged in raw source.
All four retained actual cases preserve ratios1.2000000476837158 or
1.3157999515533447 through normalization, measurement, save and reopen.

Raw SDK font families containing comma, quote or escape syntax, or equal to CSS
font generics, refuse admission before editable preview bypass. Their literal
native family cannot yet be proved equivalent to the canonical CSS family-list
representation; no alias is substituted and raw source/fallback stays retained.
Font face/style/weight, alignment, letter spacing, paragraph/list/variable and
paint/link context must fit the existing canonical subset. Only supported uniform
metrics may carry paint/link ranges. Canonical intent admission is distinct from
native-create eligibility. Bad hints leave independently admitted current intent
untouched; successful hint restoration applies only `{fill, textRanges}` after
snapshot, plugin/key, current source and effective plan checks.

The complete supplemental public import route descriptor-clones owned JSON
before serialization, so accessors or toJSON cannot hide bytes. Each full
REST+observation proof is capped at256KiB; hint restoration at64KiB, native
pluginId+key+value at100000UTF8 bytes, and the complete export/import envelope at
16MiB including nodes, sources, raw hints, Base64 assets, SVG previews, warnings
and selection. Entries are never truncated to manufacture acceptance.

## Preview and flow limits

Admission can bypass only a leaf Text's own mixed-fill preview reason after the
complete independent paint/link-only proof. It cannot suppress masks, unsupported
paint/stroke/effect/blend causes, malformed children or an ancestor image fallback.
The original preview and asset remain saved for fallback. A public supplemental
flag supplies no preview authority. When raw REST would allow own mixed-preview
bypass, private initial and final SDK snapshots must also prove no independent
mask, visible stroke/effect or blend cause on that Text and its actual Scene
ancestry, including ancestors outside a selection export. Supported ancestor
paint must pass the existing editable paint gate. Otherwise export explicitly
refuses, instead of publishing a proof that could cancel an actual preview cause.
Page/Document retain topology checks without inventing Scene paint fields.

The existing HUG Grid raw rich-text refusal relaxes only for independently proven
uniform paint/link metrics. A synthetic composition of retained native padded
rows and retained rich Text keeps real Grid/Fill/Hug and ordinary content growth.
Incomplete catalogs and unsupported paragraph variants still refuse that flow.
This is a CPU model regression, not a new native Grid or responsive pixel proof.

Explicit nonempty whitespace may wrap without trimming its source. Empty source
remains distinct from absent source; empty wrap and blank ellipsis remain invalid.
Tests construct actual NBSP/CR/LF/emoji code units independently, assert LF offsets,
and cover measurement, content edits, HUG growth and save/reopen. CanvasKit/SVG
still use display lines and frontend/native content uses the retained source.
No broader CRLF shaping, renderer equivalence or glyph pixel claim is made.
