# 视频工作台与 OpenCut：能力对比及精剪优化

调研日期：**2026-09-15**。

## 比较基线

- **发布与现机基线：视频工作台 0.5.12**，发布源码提交 `2149c34087c5e692abe10ba36fa4082d7a416a34`。本次安装前核查，本机实际版本也是 **0.5.12**；此前文档中的 0.5.9 已不代表当前状态。
- **前一阶段：0.5.13 候选**，在 0.5.12 上补齐独立音轨直接精剪、拖动控制和长时间轴导航，画面仍按主序列顺序排列。
- **本次本机更新：0.5.14**，继续增加单画面轨自由定位与空隙、独立排列/吸附开关、空隙预览和导出，以及参考录音提取后的恢复保存入口。已通过正式本地审核安装接口更新本机安装包；此前打开的面板需关闭标签后重开加载新包，未发布到 GitHub。
- **OpenCut Classic：**固定提交 [`cf5e79e919144200294fb9fed22a222592a0aeea`](https://github.com/OpenCut-app/opencut-classic/tree/cf5e79e919144200294fb9fed22a222592a0aeea)。Classic 已归档；OpenCut 主仓正在重写，官方说明现有站点仍运行 Classic。Editor API、第三方插件、MCP、无界面运行及脚本页属于重写规划，不能当作当前已成熟能力。见[官方状态说明](https://github.com/OpenCut-app/OpenCut#status)。

本次核验包含工程模型、实际交互和渲染源码。面板已经管理媒体制作与模型运行，CodeShell 提供通用任务、授权和资源能力；后续领域功能应继续随面板更新。

## 已具备，不能作为缺口

旧版 0.4.7 的观察不能用于评价 0.5.12。以下能力已在发布源码中核验：

- **0.5.7 素材管理**：名称/路径搜索、类型筛选、导入顺序/名称/时长排序、大图/小图/列表视图、素材多选、全选当前结果、单个/批量删除、右键与更多菜单，视图偏好持久保存。
- **批量粗剪**：素材多选队列、逐条保留段、批量处理与 AI 辅助粗剪已经存在。素材多选与成片时间轴的多片段选择是两项能力，不能混为一谈。
- **0.5.11 入轨与封面**：素材入轨后切回成片、选中新片段并定位到起点，必要时自动滚动；时间轴使用真实素材封面持续平铺，已解决旧版第 8 张之后空白的问题。平铺复用同一张真实封面，尚不等于不同源时刻的连续缩略图。
- **0.5.12 右键删除**：画面与音频片段都可从时间轴右键删除，保留素材库与原文件，并支持撤销。
- **既有编辑流程**：视频切分、拖边裁剪、顺序重排、音量、左右键逐帧、字幕联动、独立混音、SRT、撤销/重做、录制、本人声音与实际视频导出。

对应源码为 [`media-library-ui.ts`](../apps/video-studio/src/media-library-ui.ts)、[`views.ts`](../apps/video-studio/src/views.ts)、[`main.ts`](../apps/video-studio/src/main.ts)、[`timeline-context-menu.ts`](../apps/video-studio/src/timeline-context-menu.ts) 和 [`style.css`](../apps/video-studio/public/style.css)；版本记录见[面板 README](../apps/video-studio/README.md)。

## 0.5.13 前一阶段实施范围

以下功能已实现，已在 0.5.12 原有流程上完成回归验证。

1. **音轨直接精剪**：拖移音轨、拖动两侧裁剪源范围、切分所选音轨。切分按源入点与播放头转换，不能误切下方画面；保留原素材并支持撤销/重做。
2. **拖动控制**：显示拖动预览；N 开关对齐吸附，按住 Alt 临时暂停，Escape 取消。这个版本仍只有主画面顺序重排，关闭对齐吸附不会让视频按时间自由定位。
3. **长时间轴可读性**：适应全长缩放、自适应标尺、按可见范围绘制刻度；保留逐帧定位和现有封面平铺，避免长项目创建大量屏外刻度。
4. **快捷导航与说明**：Home/End 定位起止，向上/向下跳切点，Shift+左右跳 5 秒，并提供快捷键说明。素材预览、粗剪、文字输入、对话框和右键菜单仍遵守各自的交互上下文。

验收重点是源范围正确、拖动取消不写工程、一次操作可整体撤销、旧工程可恢复、音频与字幕联动不被破坏，以及长时间轴和窄面板仍可操作。素材管理、批量粗剪、入轨定位、录音和右键删除均为发布基线能力，必须保留。

## 0.5.14 本次实施范围

1. **画面可按时间自由放置**：点击“磁吸排列”或按 **M** 切到“自由排列”，拖动画面可放到任意有效时间，也可在右侧输入精确位置；从素材库拖入时使用落点时间。单画面轨允许留空，不允许片段重叠。重新开启磁吸排列会按时间顺序收拢空隙，切换可撤销。
2. **排列与边缘吸附分别控制**：**M** 决定是否允许自由位置与空隙，**N** 只控制边缘对齐吸附。按住 **Alt** 临时暂停吸附，**Escape** 取消当前拖动；关闭 N 不会自动切换排列模式。
3. **编辑保留已有空隙**：自由模式中移动、裁剪、分割、删除与加入片段均使用实际时间位置，不推移其他画面。字幕按所关联的源范围跟随，原有空隙中的字幕保留；独立音乐/配音保持绝对时间位置。总时长由最晚画面末端决定，缩短总长时裁掉超出末端的音轨与字幕。旧工程未指定模式时继续使用原磁吸序列；口播自动删减需要先切回磁吸，避免静默压紧自由排列。
4. **空隙真实参与播放和导出**：画面前方与片段之间的空隙显示黑场，预览和 WebM 继续推进时间轴，独立音乐/配音按原时序播放；播放头与配音使用一致的时间轴时钟。MP4 导出也写入对应长度的黑场，不把空隙跳过或压缩。
5. **参考录音提取结果可恢复保存**：提取完成但未保存到工程时显示明确状态，提供“恢复保存”和结束本次准备入口。恢复沿用已完成任务结果，不重新提取，不把结果绑定到其他工程。已保存录音仍通过“配音 → 创建我的声音 → 提供本人录音”试听或定位素材库，这是 0.5.12 已有入口。

适应全长、上下跳切点、快捷键安排和提取恢复是针对工作台的改良，不宣称 Classic 有完全相同的按钮或快捷键。0.5.14 之后仍需补齐的是复制、时间轴多选、真实波形、多画面轨、构图、变速、关键帧和审阅标记；**素材筛选排序、多视图、多选删除、封面平铺、右键删除和单轨自由留空不再列为候选版本缺口**。

## 实现与渲染边界

- [`model.ts`](../apps/video-studio/src/model.ts) 定义工程、片段与原子编辑。0.5.12 以源入出帧差累计主序列时长；0.5.14 增加可选 `timelineMode` 和片段 `startFrame`，以实际末端计算自由模式总长，仍无变速、构图或关键帧属性。
- [`views.ts`](../apps/video-studio/src/views.ts)、[`main.ts`](../apps/video-studio/src/main.ts) 定义时间轴和交互；[`media.ts`](../apps/video-studio/src/media.ts) 定义浏览器画面、混音和 WebM 导出。
- [`native/media/media-processors.ts`](../apps/video-studio/native/media/media-processors.ts) 是随面板发布的实际媒体处理与 MP4 导出实现；0.5.14 将空隙编排为黑场片段，仍明确拒绝未支持的 crop、zoom、speed 操作。添加这些属性时，应同时支持工程恢复、预览、浏览器 WebM 与面板本地 MP4 导出，而不是把领域规则重新加入 Host。
