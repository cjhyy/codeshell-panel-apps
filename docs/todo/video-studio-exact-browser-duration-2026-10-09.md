# 浏览器素材精确时长

本包修复文件选择、拖放和浏览器录制仍把新素材时长保存为 30fps 整帧的问题，
同时让独立浏览器的实时 WebM 导出读取完整多轨工程。已连接的 Desktop、配对
Web、Hub Web 和 Hub Mobile 继续使用已有的原生任务导出入口。

## 保存合同

- 工程时钟保持每秒 240000 tick。新素材使用真实解码或原生 inspection 时长；
  10003 个 48kHz 采样保存为 50015 tick，7 个 30000/1001fps 视频帧保存为
  56056 tick。展示用的旧视图帧数不再决定新素材时长。
- 原片持久化先于工程元数据。普通文件选择、拖放和浏览器录制也等待工程的
  durable save；失败时保留旧工程，并释放未发布的本地解码器。
- 原生导入、录制和 preparation 的 inspection 通过一次发布回执传入真实 Main
  消费者。仅新素材采用检查时长；重连、重新检查和旧工程迁移不延长已有素材，
  不重写已有片段的 timeMap。
- 正时长小于一帧的素材保留旧视图的库/缓存身份。旧视图仍标记 asset-tail，
  不能声称其整帧投影能够完整渲染。工程 schema、数据库版本及历史备份不变。

## 独立浏览器 WebM

导出冻结完整工程及 Session identity，复用共享求值器、画面合成器和音频计划。
每个重叠音频实例有独立解码器，按实际原音时钟前进；无声音的区间用
AudioContext 时钟。素材准备、seek、播放、画面等待后均重验 owner 与取消，
悬挂的 resolver/play 有取消和超时门限，迟到的 owned URL 仍释放。

支持旧 renderSafe 工程原有的画面、字幕、音轨、偏移、音量和静音；共享画面
合成器也可处理完整工程的画面层。原先旧视图就不支持的变调、音频变速和
ducking 在获取素材前说明需要原生导出，不扩大浏览器 DSP 能力声明。

WebM 仍是实时编码输出，耗时接近序列时长、最长 10 分钟、进入后台时取消。
保存的源与时间线精确；编码容器允许末帧和 Opus 包的尾部时差，不宣称离线
逐采样编码。末尾画面与已排队音频在停止编码前完成呈现/排空。
结束、取消、owner 变更和编码失败均释放 capture/destination tracks、声音
解码器、AudioContext、画面池和 owned URL；borrowed URL 不由导出器撤销。
编码器 stop 与 AudioContext close 的收尾等待也保留取消、可见性和 owner
监测；清理完成后再次检查原始取消信号，已取消的编码结果不会下载。
生产 Main 在收到编码结果后、开始下载前也直接重验原始取消信号与可见性，
覆盖异步导出完成与调用方继续执行之间的 microtask 失效窗口。

## 验收

`tests/video-studio-exact-browser-duration.test.mjs` 使用真实 FFmpeg 源文件和
完整产品界面，覆盖 chooser/drop/合成摄像头的保存、冷恢复与精确放置，
1-sample 素材、保存失败后重试及旧整帧工程重连。实际下载的 WebM 经 FFmpeg
解码检查最后蓝色画面、非整帧尾音和相邻同源两次尾音。

`tests/video-studio-browser-export-media.test.mjs` 使用真实浏览器编码与解码 PCM，
检查静音、增益比例、不同 source offset 的同源重叠、共享 owned URL 在画面和
声音均释放后只撤销一次、第二素材延迟 250ms 的相邻尾音，以及悬挂 resolver/play、owner 变更、
提前 EOF 和编码器构造失败时的清理。真实 MediaRecorder 已停止但延迟交付
stop 事件时，取消、切后台和 owner 变更均拒绝返回文件；AudioContext close
尚未完成时取消也保留相同保证。每个夹具只使用合成媒体及 blob URL；
不访问真实摄像头、个人工程、外部账号或付费模型。

完整生产 Main 回归另在真实 WebM Blob 完成后、下载调用方继续执行前排入
microtask，点击现有取消按钮或注入未发通知的隐藏状态；两种情况均不得触发
真实浏览器下载。隐藏状态是受控夹具，不冒充操作系统窗口切换验收。

原有摄像头回归改读实际持久化的多轨片段/尺寸/时长，保留实际导出文件的
可解码音量断言，并检查导出不修改工程。原生录音 Main 夹具使用真实
10003-sample WAV，通过受控 inspection、保存失败、重开和重复挂接检查
50015 tick 只发布一次；这不是已安装 Desktop 的真人录制验收。
组合可信云端视频采集后，另以真实 7 帧 NTSC WebM 和 FFprobe 检查结果走
同一发布入口，保留容器检查时长对应的 tick，重复挂接与冷重开均不量化或
重复采集。该检查来自合成文件，不冒充真实云端摄像头权限验收。

新增用例进入既有 offline/UI/media 门禁，CI 保留实际编码 WebM。完整组合
门禁和最终提交/CI 结论记录在本包 PR；未发布版本不作为用户安装验收完成。

## 保留边界

- 浏览器音频变速、变调和 ducking 的完整 DSP parity 仍依赖原生导出。
- 真实设备、安装后的 Desktop 和真实已配对 Web/Hub 交付验收需独立进行，
  本包受控夹具不冒充真实账号或实际设备验收。
- `?legacyWorkspace=1` 的旧 AI 轨道只投影整帧片段：导入 10003-sample WAV 并
  完整粗剪加入后，50015-tick 音频不会出现在该旧轨道中。正式入口和「素材」页
  使用现代 timeline，可选择、预览和撤销该片段；原旧 renderSafe 整帧流程仍保留
  完整用户动作回归。本包不宣称旧调试 AI 轨道支持 fractional 片段。
- `main.ts` 后续拆分不在本包范围内。
