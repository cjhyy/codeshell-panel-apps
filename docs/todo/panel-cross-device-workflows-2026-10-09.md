## 继续改造：业务闭环

在上述首批基础上继续补齐实际业务缺口，没有安装到个人项目或发布版本。

- Video Studio：接入可信工作台 `resources.recordVideo` 和独立设备能力发现。
  摄像头／录屏选项按真实能力显示，声音参考只允许音频；屏幕声音如实显示实际
  取得的音轨。原片保存和加入工程分开，回执丢失、保存失败及不支持采集的设备
  都可从项目文件恢复；视频检查实际类型、时长及尺寸，重复加入不重复入库。
  旧 Host 保留录音入口。Host 通用采集实现属于独立仓库改动，iframe 权限未放开。
- Job Hunt HQ：定时发现采用固定业务键唯一创建、条件版本修改／删除；读失败
  不当成空任务，历史重复项先核对，未知写入结果先只读刷新。旧 Host 明确降级；
  暂停、继续和立即运行没有原子版本接口，采用操作前后核对并提示避免多端并发。
- Quant Lab：识别同一路径下的会话切换，初始读取不覆盖较新的上下文；排队的
  旧绑定写入不进入新项目。未保存参数按执行绑定暂存，备份可选择当前或旧绑定的
  草稿，并通过原备份入口明确载入；项目持久存储键和配置格式不变。手机恢复
  保存策略、保存报告入口。
- Design Studio／Quant Lab：独立浏览器预览和受限 Host 显示真实 Agent 能力，
  不再伪造任务已接收；保留实际本地创建、保存、备份及导出流程。

续改验证包含真实 Chromium 的窄屏本地业务、双页面并发、上下文初读竞态、
回执丢失及保存重试。Video 主界面用真实 FFmpeg 视频及 ffprobe 信息验证工程
入库、去重和重开，Host 另验真实浏览器编码和上传字节。具体计数以本轮最终
检查记录为准；浏览器设备夹具不代表实体手机或目标服务器验收。
