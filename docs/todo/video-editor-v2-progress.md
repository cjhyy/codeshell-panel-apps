## 技术约束

- `TimeMap` 的源反查采用离散整数刻度的半开范围，倒放边界有明确测试。
- 多机位源时间 = 共用时间映射 + 机位的有符号 offset；主音频机位连续，不随画面切换。
- `TextStyle.layout=caption-stack` 用于保留旧字幕的底部堆叠，`box` 用于自由文字；shadow 为显式属性。
- 调色温度/色调为归一化偏移，曝光为档数；当前色彩模型 SDR sRGB，不能宣称 HDR 管线。
- 原生导出使用相同合成器；不得继续用旧 concat 管线忽略新版字段。
- 图片需要冻结首帧，不能让 GIF/动态 WebP 随墙钟变化；媒体池后续小修复已交给音频代理。
- 导出画布比例不同于序列时保留构图并留边；编码显式标记 SDR sRGB/BT.709 色度，测试视频源也必须有准确色彩信息，避免未标记601/709矩阵造成虚假误差。
- Host 资源/任务上限需通过依赖闭包和分批准备处理，不能将全部媒体和大文档一次塞入请求。
