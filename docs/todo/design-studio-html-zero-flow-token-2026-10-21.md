## Current private proof

Only the current HTML importer creates a single-use opaque frozen handle backed
by a private WeakMap. JSON, notes, callback lookalikes and public mutable token
sets cannot authorize omission. The proof binds exact original source objects,
source parent/child indexes, semantic identity, current Element/document/ancestry,
world boxes, direct DOM child order and current layout/style. It preserves the
original indexes when converting every remaining real child.

Admission requires an empty, nonreplaced, static inline element with one exact
0×0 client rectangle, no child nodes, no transform/float/clear/inset contribution,
no border/padding/margin, paint, outline, shadow, filter, mask or generated content.
Counter reset/set/increment, quote content, containment, nonhorizontal/RTL flow,
animations/transitions, intrinsic/control/break elements and interactive or ARIA
semantics refuse. Any id or name refuses, preserving navigation/source-binding
and potential prototype destinations even when no local href is currently visible.

The parent must have ordinary block flow with no anonymous authored text; only
collapsible ASCII whitespace is permitted in a normal white-space context.
Other rendered in-flow siblings must be positive ordinary block/Flex/Grid boxes.
This restriction prevents empty inline tokens from manufacturing line boxes.
Actual empty span and undefined custom-element controls qualify; defined custom
elements or late upgrades refuse. A null observable shadowRoot alone is never
used to prove absence of a closed root. The capture registry and current liveness
are separately checked. This is a current capture proof, not a blanket assertion
about the public site's scripts or future upgrades.

Descriptor-owned typed source snapshots refuse accessors/toJSON, cycles, unusual
prototypes, functions and oversized fields without invoking them. Source snapshots
limit32768 input key/string UTF-16 units,2000 values,depth10 and4000 units per
string. Style reads limit16384 input string units and4000 per value. Retained
serialized snapshot strings are capped at524288 UTF-16 units per parent and
2097152 per capture, with at most100 accepted parents/500 reported tokens. These
are code-unit limits, not encoded UTF-8 byte claims. Existing source/geometry/
resource/document budgets remain intact.

The adapter applies the capability only after ordinary block recovery succeeds.
After all image, measurement and table awaits, the importer synchronously
rechecks every accepted token/source/parent/order/style. A late change aborts the
capture and closes its iframe; it cannot publish a document with stale omission.
An actual image-hash await test changes an empty token's box-shadow and verifies
that final refusal. Original-node/range guards and native code remain unchanged.
