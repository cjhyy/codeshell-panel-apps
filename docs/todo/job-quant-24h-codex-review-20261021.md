# Codex 审核 CC 方案

审核人：当前 Codex 主代理。CC 原文见 `job-quant-24h-cc-plan-20261021.md`。

结论：采用复用现有域逻辑、公开 CLI 与面板共享数据、白话报告和有限观察的方向；以下修正优先于原方案。

1. 用户已授权24小时自主推进、开发与验收。例行工作、模拟、必要安装与有截止的调度不重复请求批准。实盘、投递、联系第三方仍不在本轮范围。不得把纯行情观察代替自主开发/验收。
2. 先完成真正可用的两个产品闭环，再做增强：求职的岗位/公司研究操作抽取、证据对照与日报、CLI/UI一致；投资的预设、白话报告、同口径UI、明确合成演示。不能只交付文档或脚本。
3. 取消无校准依据的新匹配分数。新证据对照展示命中的JD原句、已确认资料原句、缺口与未知约束；旧Agent分数仅标为未核验，不冒充可信匹配概率。不得将未确认草稿或仓库描述当本人事实。
4. HTTP200或页面标题存在不等于仍在招；只有确实读取官方/ATS岗位证据并确认在招语义才允许相应核验状态。普通可达、登录、未知和已关闭分开。网络核验若实现，必须校验DNS解析后的实际公网地址、重定向、响应上限/超时，不能只拒绝IP字面量。通用抓取不完善时明确使用已有Agent/浏览器核验路径，不交付虚假的verified状态。
5. JD附件与主快照提交复用既有安全协议。优先不可变、幂等、先写附件后CAS引用；允许未引用孤儿附件，不回滚删除可能被其他写入者引用的文件。新字段经过规范化、分片、往返与Panel后续保存仍必须保留。
6. 不改变回测成交行为或固定引擎结果。明确收盘信号/下一根开盘、双边费用、零碎股、期末强平、入场当天不检查止损、未建模A股手数/涨跌停等限制。基准是首根收盘买入持有且未扣费。不能声称成本完全同口径或A股可执行。
7. 默认费用沿用显式的研究假设；不把5.5bps近似称为当前市场规定费率。费用和滑点金额若不能准确还原，标为估算；最大回撤金额取真实峰谷差，不用本金乘最大回撤比例冒充。
8. 样本外不足时明确未运行/不足；各折重置本金，不能冒充连续复利实盘。全样本最优参数不当作样本外结果。少量新手预设是实验规则，没有收益承诺。
9. 数据侧车缺失与坏数据/越权路径分开处理。来源、复权、时点未知应可见；符号链接、超限、越界不能被静默降级吞掉。合成数据明确标注，演示和测试不得进入个人事实/真实岗位。
10. 观察运行器先实现单轮tick、状态、日志、绝对截止、停止和单实例，注入时钟做测试。锁不凭年龄删除活跃持有者；拒绝路径穿越/符号链接。launchd由本轮交付稳定包后启动，包安装不可依赖可清理worktree。截止仍为2026-10-22T03:08:05Z，报告实际时长，不宣称已跑完24h。
11. 原方案的现状已更新：两个完整suite均已拿到exit0（求职356、投资Node228）。安装版求职4.2.1有CLI，投资0.46.1无CLI且未绑定；调用已安装求职Panel曾未ready，必须做真实安装与打开验收。
12. 后台接续的Host通用缺口已单独调查并独立处理；本业务worktree不得修改Host。MCP前台调用曾300秒超时，CC最终方案已从原会话恢复，不能把超时当业务失败或重复启动同一任务。
13. 实现中主代理的独立检查见 `job-quant-24h-parent-findings-20261021.md`。验收必须复核其P1日报证据复制导致约2.9MB输出，以及P2无岗位但已有资料时错误宣称缺资料；修复后通过回归才能关闭。
