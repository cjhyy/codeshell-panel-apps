CodeShell Design Bridge

通过本地 JSON 连接 Figma 与设计面板。支持基础图层和 Auto Layout；不支持二进制 .fig 文件。

Figma → 设计面板

下载官方 JSON_REST_V1 数据，再在设计面板的「导入 Figma JSON」中打开。

查看或复制导出的 JSON

完成导出后，可直接复制内容，也可重新下载文件。

设计面板 → Figma

选择 CodeShell Design v3、完整备份（完整设计文件）或 Figma 传输包，创建可编辑的新页面。只有来源绑定的 Figma 传输包可增量更新原设计。

文件无法选择？粘贴设计 JSON

可粘贴普通 v3、含图片与字体的完整备份，或 Figma 传输包。完整文件上限 128 MiB；转换后的 Figma 图层传输上限 16 MiB。

准备就绪。所有文件处理均在本地进行。
