CodeShell Design Bridge

通过本地 JSON 连接 Figma 与设计面板。支持基础图层和 Auto Layout；不支持二进制 .fig 文件。

Figma → 设计面板

下载官方 JSON_REST_V1 数据，再在设计面板的「导入 Figma JSON」中打开。

查看或复制导出的 JSON

完成导出后，可直接复制内容，也可重新下载文件。

设计面板 → Figma

选择设计面板导出的 Figma 传输包。可创建新页面；有来源记录时也可核对后增量更新原设计。

文件无法选择？粘贴转换 JSON

粘贴设计面板导出的 Figma 传输包内容，校验后使用下方导入或更新按钮。单次上限 16 MiB。
